# 地方競馬14場 コースデータ調査メモ

高知競馬場以外の13場を今後追加実装する際の下調べ資料。帯広競馬場(ばんえい競馬)は通常のサラブレッド競走と仕組みが異なるため対象外。

**出典**: 地方競馬全国協会(NAR)公式サイト「コース一覧」(https://www.keiba.go.jp/guide/course/)、同協会発行「地方競馬総合ガイドブック2024」(https://www.keiba.go.jp/pdf/about/sougou/2024/sougou_3.pdf)を主な一次資料とし、コーナーの質的特徴などの補足はオッズパーク/うまめし競馬等で照合。両公式資料の数値は一致。

**注意点**:
- コーナー数(4個/周)はいずれの公式資料にも明示的な数値記載がなく、解説文中の「1〜4コーナー」という表現からの推定。
- 「主な開催距離」は公式コース図のゲート位置表記をそのまま抽出したもので、実際の開催頻度までは未確認。
- 1周の中でのコーナー/直線の区間内訳(どこからどこまでが向正面か等)は、`scripts/track_presets.gd` の高知競馬場と同様、公式資料に記載がないため実装時は目安配分が必要。

---

### 高知競馬場(実装済み・`scripts/track_presets.gd`参照)
- 1周距離: 1100m(ダート) / 直線: 230m(ゴールまで200m)
- コーナー: 1・2コーナーが3・4コーナーより小回り。高低差1.58m。内側の砂が深く外を回る傾向
- 主な開催距離: 800, 1000, 1100, 1300, 1400, 1600, 1800, 1900, 2100, 2400m

### 門別競馬場
- 1周距離: 外回り1600m / 内回り1376m(ダートのみ) / 直線: 外回り400m(ゴールまで330m)、内回り288m(ゴールまで218m)
- 右回り、幅員25m、高低差1.54m。直線が長くカーブが緩やかな大箱。大井・盛岡と並ぶ地方最大級
- 主な開催距離: 1000, 1100, 1200, 1500, 1600, 1700, 1800, 2000, 2600m

### 盛岡競馬場
- 1周距離: ダート1600m / 芝1400m(地方競馬で唯一の芝コース併設) / 直線: 400m(ゴールまで300m、芝・ダート共通)
- 左回り、幅員25m、高低差ダート4.4m・芝4.6m(地方競馬最大級)。起伏に富んだ大箱
- 主な開催距離: 1000, 1200, 1600, 1700, 1800, 2000, 2400, 2500m(芝/ダート別までは未確認)

### 水沢競馬場
- 1周距離: 1200m(ダート) / 直線: 317m(ゴールまで245m)※民間サイトでは300m/245mとする表記もあり
- 右回り、幅員20m、高低差なし(平坦)
- 主な開催距離: 850, 1200, 1300, 1400, 1600, 1800, 1900, 2000, 2500m

### 浦和競馬場
- 1周距離: 1200m(ダート、地方最短クラス) / 直線: 300m(ゴールまで220m)
- 左回り、幅員16.5〜24m、平坦。小回りでタイト。第3コーナーがスパイラルカーブ化改修済み
- 主な開催距離: 800, 1200, 1300, 1400, 1500, 1600, 1900, 2000m

### 船橋競馬場
- 1周距離: 外回り1400m / 内回り1250m(ダート) / 直線: 362m(ゴールまで308m)
- 左回り。南関東4場唯一のスパイラルカーブ。コーナー内外に高低差あり。直線は地方競馬では長め
- 主な開催距離: 800, 1000, 1200, 1400, 1500, 1600, 1700, 1800, 2000, 2200, 2400m

### 大井競馬場(東京シティ競馬/TCK)
- 1周距離: 外回り1600m / 内回り1400m(ダート) / 直線: 外回り(右)486m(ゴールまで386m)、外回り(左)486m(ゴールまで300m)、内回り(右)386m(ゴールまで286m)
- 世界唯一、左右両回り可能。地方最長クラスの直線。平坦、幅員25m
- 主な開催距離: 1000, 1200, 1400, 1500, 1600, 1650, 1700, 1800, 2000, 2400, 2600m

### 川崎競馬場
- 1周距離: 1200m(ダート) / 直線: 400m(ゴールまで300m)
- 左回り、平坦。周長はコンパクトだが直線が長めで、コーナーが急
- 主な開催距離: 900, 1200, 1400, 1500, 1600, 2000, 2100m

### 金沢競馬場
- 1周距離: 1200m(ダート) / 直線: 286m(ゴールまで236m)
- 右回り、幅員20m、平坦。4コーナー全てにポケット(発走地点)あり
- 主な開催距離: 900, 1200, 1300, 1400, 1500, 1700, 1900, 2000, 2100, 2300, 2600m

### 笠松競馬場
- 1周距離: 1100m(ダート) / 直線: 238m(ゴールまで201m)、向正面251m
- 右回り、高低差1.92m(向正面が下り坂)。小回りで追い込み難。砂質良好
- 主な開催距離: 800, 1100, 1400, 1600, 1800, 1900, 2500m

### 名古屋競馬場(弥富、2022年移転後)
- 1周距離: 1180m(ダート) / 直線: 300m(ゴールまで240m)
- 右回り、平坦、幅員約30m。第3・4コーナーがスパイラルカーブ
- 主な開催距離: 900, 920, 1500, 1700, 2000, 2100m

### 園田競馬場
- 1周距離: 1051m(ダート、日本最短クラスの小回り) / 直線: 241m(ゴールまで213m)、向正面246m
- 右回り、高低差1.23m(向正面〜3コーナーが上り坂)
- 主な開催距離: 820, 1230, 1400, 1700, 1870, 2400m

### 姫路競馬場
- 1周距離: 1200m(ダート) / 直線: 350m(ゴールまで230m)
- 右回り、高低差なし(平坦)、幅員20〜25m
- 主な開催距離: 800, 1200, 1400, 1500, 1800, 2000m

### 佐賀競馬場
- 1周距離: 1100m(ダート) / 直線: 250m(ゴールまで200m)
- 右回り、高低差1m(ほぼ平坦)、幅員19.2〜24m。砂が粗く力のある馬向き。先行馬有利の傾向
- 主な開催距離: 900, 1100, 1300, 1400, 1750, 1800, 1860, 2000, 2400, 2500m
