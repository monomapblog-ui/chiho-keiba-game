# 地方競馬ジョッキーアクション(仮称)

地方競馬をモチーフにした、レース中ずっと操作し続けるジョッキー操作アクションゲーム。

## 現状(2026-11-09時点)

[VS BOAT](https://vsboat.app)(3D・セルシェーディング・ガチャ等のソーシャル要素を持つ
公式ボートレースアプリ)を参考イメージとして、**Unity・3Dで本格的に作る方針**に
切り替えました。時間をかけて3Dを学びながら進める前提です。

- **`unity/`**: 現在進行中のUnity版。セットアップ手順は `unity/README.md` 参照
- **`godot-prototype-archive/`**: 最初に作ったGodot・2Dのプロトタイプ(操作ロジックの
  検証用。開発は停止していますが、ゲームデザインの参考として残しています)
- **`docs/tracks_nar_research.md`**: 地方競馬14場のコースデータ調査資料(エンジンに
  依らず使う参考資料)

## これは何で、何ではないか(重要)

- **登場する馬名・騎手名は架空**です。実在の競走馬・騎手とは一切関係ありません。
  個人開発でJRAや地方競馬主催者・騎手本人から実名使用の正式な許諾を得るのは
  現実的に難しいため、この部分は架空の名前で進める方針です。
- **競馬場名とコース形態(高知競馬場)は実在のものをモデルにしています。** 1周の
  距離・最終直線の長さ・コーナーの特徴は、地方競馬全国協会(NAR)公式資料を
  出典としています。詳細は `docs/tracks_nar_research.md` 参照。
- **VS BOAT級の3Dクオリティには、まだ全く届いていません。** 現在のUnity版は
  直方体のプレースホルダーで動く、カメラ・操作・レースロジックの土台段階です。
