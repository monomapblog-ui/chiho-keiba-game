# 地方競馬ジョッキーアクション(仮称・プロトタイプ)

地方競馬をモチーフにした、**レース中ずっと操作し続けるジョッキー操作アクションゲーム**のプロトタイプです。
「スタート一瞬だけ」ではなく、レース展開中のペース配分・スタミナ管理・レーン取りを継続的に操作する体験を目指しています。

## これは何ではないか(重要)

- 登場する馬名・騎手名・競馬場名(白鷺競馬場など)は**すべて架空**です。実在の競走馬・騎手・団体・競馬場とは一切関係ありません。
- 能力値の「傾向」(スピード型/スタミナ型など)は競馬というジャンルの一般的な特徴を参考にしていますが、特定の実在馬・実在騎手のデータを使ったものではありません。
- 現時点では見た目は仮(色付き四角)で、絵・音は未実装のロジック検証用プロトタイプです。

実在の馬名・騎手名を使うかどうかは開発初期に検討し、個人開発でJRAや地方競馬主催者・騎手本人から正式な許諾を得るのは現実的に難しいため、架空の名前で進める方針にしています。

## 操作方法

| 操作 | キー |
|---|---|
| 押す(ペースアップ、スタミナ消費大) | ↑ または W (長押し) |
| 抑える(ペースダウン、スタミナ回復) | ↓ または S (長押し) |
| レーンを内側へ | ← または A |
| レーンを外側へ | → または D |

プレイヤーは常に先頭(赤い四角)です。青い四角はCPU(脚質に応じて自動で動きます)。

## 動かし方

1. [Godot Engine 4.x](https://godotengine.org/download) をインストール(開発時点の動作確認バージョン: **4.7.2**)
2. Godotを起動し、「インポート」からこのリポジトリの `project.godot` を選択
3. 右上の再生ボタン(▶)でメインシーンを実行

## プロジェクト構成

```
scripts/
  horse_stats.gd    馬1頭分の能力値(架空データ)
  track_data.gd     コース定義(距離・コーナー位置など)
  horse_runtime.gd  レース中の状態更新ロジック(速度・スタミナ・バテ処理)。ノード非依存
  race_world.gd     複数頭のレース進行管理。前の馬が詰まった時の速度頭打ち(ブロッキング)もここで解決
  ai_controller.gd  CPU馬の脚質別の簡易な意思決定ロジック
  main.gd           実際にプレイする画面(入力受付・描画)。ノードはすべてコードで組み立てている
scenes/
  Main.tscn         main.gdをアタッチしただけの最小シーン
test/
  race_sim_test.gd  画面なしでレース1本分をシミュレートする自動テスト
```

`horse_runtime.gd` / `race_world.gd` / `ai_controller.gd` はシーンツリーに依存しない素のロジックにしてあるので、
Godotエディタを開かなくても次のコマンドで動作確認できます。

```sh
godot4 --headless --script res://test/race_sim_test.gd
```

## 現状のバランス(v1・暫定)

1400mのコースを、CPU4頭(脚質:逃げ/先行/差し/追込)がAI操作のみで走ると、完走タイムはおおむね90〜100秒程度になるよう調整しています。
実際にプレイしてみての手応え(操作の忙しさ、スタミナ切れのタイミング、追い抜きの気持ちよさ)を見ながら、今後調整していく前提の暫定値です。
